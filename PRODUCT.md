# Product

## Register

brand

## Users

Noosphere is for developers, AI tool users, and small technical teams that move between Codex, Claude Code, Cursor, local models, IDEs, and HTTP/MCP clients while working on the same repository. They arrive with a concrete concern: agent work often loses decisions, constraints, handoffs, and verification evidence between sessions.

## Product Purpose

Noosphere provides a shared project-memory layer for AI agents. It captures concise project findings and stores them through Walrus Memory so another agent can recall relevant context by meaning and continue without replaying the whole repository history. The public website should make the product feel durable, alive, and technically credible while still giving local users access to the existing memory controls.

## Brand Personality

Alive, rigorous, and infrastructural. The voice should feel like a living technical system rather than a dashboard template: confident, precise, and a little uncanny, with motion used to explain memory continuity instead of decorating the page.

## Anti-references

Do not copy Buzzworthy Studio's identity, palette, page layout, or agency copy. Use its pulsing 3D hero energy only as a motion reference. Avoid generic SaaS cream pages, dashboard-first product UI, repetitive icon-card grids, artificial metrics, and terminal cosplay.

## Design Principles

1. Make memory visible: the visitor should immediately see a living field of connected context, not a static product diagram.
2. Lead with the public story: the first viewport sells cross-agent continuity before exposing local forms.
3. Keep credibility in the copy: every claim should map to an actual Noosphere capability such as Walrus-backed storage, semantic recall, local watchers, setup, and install.
4. Motion must carry meaning: scroll and hover effects should show capture, storage, recall, and continuation.
5. Preserve the working product: existing Remember, Recall, Projects, Setup, and Install controls remain usable lower on the page.

## Accessibility & Inclusion

Target WCAG AA contrast. Provide visible focus states, readable text at mobile sizes, and `prefers-reduced-motion` behavior that removes continuous motion while preserving content and controls.
