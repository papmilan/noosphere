# SEC-05 Phase 4C Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Phase 4B trust authority with the Phase 4C append-only approval/revocation model and add a staged, authenticated, crash-safe restore workflow that never exposes an alternate writer surface.

**Architecture:** Keep `continuity/trust-store.js` as the only public authority dispatcher, but make loading it the unconditional format-2 cutover. Split cryptographic envelopes, canonical project identity, trust generations, restore candidates, confirmation contexts, apply transactions, and CLI parsing into focused internal modules; all mutations use the existing secure-filesystem boundary and all recovery decisions reauthenticate the complete transaction chain.

**Tech Stack:** Node.js ESM, built-in `node:crypto`, `node:fs/promises`, `node:test`, existing `noosphere-secure-fs`, canonical JSON, HMAC-SHA-256.

## Global Constraints

- Phase 4C loading is the authority cutover: format 1 and pre-4C format 2 are never consulted for live authority.
- Legacy records may be parsed only by the migration inventory reader; migration never grants authority and every migrated slot requires fresh interactive approval.
- All authenticated records use `HMAC-SHA-256(machine-key, canonical-json([domain, record-without-mac]))`.
- The exact domains are `noosphere/sec05/v2/project-binding`, `noosphere/sec05/v2/generation/approved`, `noosphere/sec05/v2/generation/revoked`, `noosphere/sec05/v2/authority-manifest`, `noosphere/sec05/v2/authority-audit-event`, `noosphere/sec05/v2/authority-transaction-journal`, `noosphere/sec05/v2/authority-slot-lock`, `noosphere/sec05/v2/restore-candidate-envelope`, `noosphere/sec05/v2/restore-confirmation-context`, `noosphere/sec05/v2/restore-apply-journal`, `noosphere/sec05/v2/restore-consumption-receipt`, and `noosphere/sec05/v2/restore-consumed-candidate-marker`.
- Every authenticated operation binds the digest of the canonical project identity object defined in the Phase 4C specification.
- Approved and revoked trust generations are append-only; a revoked generation is represented by the canonical tombstone schema and contains none of `rawHash`, `contentHash`, `byteLength`, `normVersion`, or `normalizedHash`.
- Restore grammar is exactly `restore stage <slot>`, `restore list`, `restore show <candidate-id>`, and `restore apply <candidate-id>`.
- Restore supports only `master-prompt`, `instructions`, and `baseline`, with the exact recall selectors and fixed destinations in the specification.
- Candidate identifiers contain 256 random bits encoded as lowercase unpadded RFC 4648 base32, are exactly 52 characters, and match `^[a-z2-7]{51}[aq]$`.
- Active restore candidates expire after exactly seven days.
- Confirmation contexts progress only `issued -> confirmed -> spent`; candidates progress only `active -> apply-in-progress -> consumed`.
- A failed apply after `apply-in-progress` consumes the candidate with a failed result; retry requires staging a new candidate.
- The final authenticated barrier runs after confirmation and immediately before the first destination temporary-file write.
- Apply recovery never repeats destination replacement and never infers success from the destination hash alone.
- Revoked-slot restore may write bytes but may not alter trust authority; restored bytes remain untrusted until a new approval.
- CLI exit codes are `0` success, `1` unexpected internal error, `2` usage error, `3` owner refusal, and `4` security validation refusal.
- Noninteractive mutation changes no authority, candidate, confirmation, destination, receipt, or consumed-marker state.
- No package export, MCP method, library API, lifecycle hook, environment variable, config field, or filesystem watcher may expose a Phase 4C writer.
- Tests must cover Linux, macOS, and Windows behavior, including hostile symlink/reparse-point, hard-link, ownership, ACL, crash, tamper, replay, and cross-domain substitution cases.

```js
// authenticated-records.js
import { createHmac, timingSafeEqual } from 'node:crypto';
import { canonicalize } from '../trust-store-internal.js';

export const AUTH_DOMAINS = Object.freeze({
  projectBinding: 'noosphere/sec05/v2/project-binding',
  approvedGeneration: 'noosphere/sec05/v2/generation/approved',
  revokedGeneration: 'noosphere/sec05/v2/generation/revoked',
  manifest: 'noosphere/sec05/v2/authority-manifest',
  audit: 'noosphere/sec05/v2/authority-audit-event',
  authorityJournal: 'noosphere/sec05/v2/authority-transaction-journal',
  slotLock: 'noosphere/sec05/v2/authority-slot-lock',
  restoreCandidate: 'noosphere/sec05/v2/restore-candidate-envelope',
  restoreConfirmation: 'noosphere/sec05/v2/restore-confirmation-context',
  restoreApplyJournal: 'noosphere/sec05/v2/restore-apply-journal',
  restoreReceipt: 'noosphere/sec05/v2/restore-consumption-receipt',
  restoreConsumed: 'noosphere/sec05/v2/restore-consumed-candidate-marker',
});

export function authenticatedMac(key, domain, record) {
  const { mac: ignoredMac, ...withoutMac } = record;
  if (withoutMac.domain !== domain) throw new TypeError('record domain does not match expected domain');
  return createHmac('sha256', key)
    .update(canonicalize([domain, withoutMac]), 'utf8')
    .digest('hex');
}

export function sealRecord(key, domain, record) {
  return Object.freeze({ ...record, mac: authenticatedMac(key, domain, record) });
}

export function verifyRecord(key, domain, value) {
  if (!value || value.domain !== domain ||
      typeof value.mac !== 'string' || !/^[0-9a-f]{64}$/.test(value.mac)) return false;
  const expected = Buffer.from(authenticatedMac(key, domain, value), 'hex');
  return timingSafeEqual(expected, Buffer.from(value.mac, 'hex'));
}
```

```js
// project-identity.js
import { createHash } from 'node:crypto';
import { canonicalize } from '../trust-store-internal.js';

const sha256 = value => createHash('sha256').update(value).digest('hex');

export function canonicalProjectIdentity({
  canonicalBindingBytes,
  canonicalRealpath,
  binding,
}) {
  const bindingIdentifier = `sha256:${sha256(canonicalBindingBytes)}`;
  const realpathHash = sha256(Buffer.from(canonicalRealpath, 'utf8'));
  if (realpathHash !== binding.realpathHash) throw new TypeError('canonical realpath does not match binding');
  return Object.freeze({
    bindingIdentifier,
    canonicalFilesystemIdentity: `sha256:${realpathHash}`,
    identitySchema: 'noosphere.sec05.project-identity',
    identityVersion: 1,
    machineKeyIdentity: binding.keyId,
    ownerScope: binding.ownerScope,
    projectIdentity: binding.projectIdentity,
  });
}

export function projectIdentityDigest(identity) {
  return `sha256:${sha256(Buffer.from(canonicalize(identity), 'utf8'))}`;
}
```

```js
export class SecurityCliError extends Error {
  constructor(code, message, exitCode) {
    super(message);
    this.name = 'SecurityCliError';
    this.code = code;

  }

export function exitCodeForError(error) {
  if (error instanceof SecurityCliError) return error.exitCode;
  if (error?.code === 'ERR_CLI_USAGE') return 2;
  if (error?.code === 'ERR_OWNER_REFUSAL') return 3;
  if (String(error?.code).startsWith('ERR_TRUST_') ||
      String(error?.code).startsWith('ERR_RESTORE_')) return 4;
  return 1;
}
```

```js
const trustGrammar = Object.freeze({
  approve: { arity: 2, slots: APPROVABLE_SLOTS },
  revoke: { arity: 2, slots: APPROVABLE_SLOTS },

function parseTrustArgs(args) {
  const [verb, slot] = args;
  const rule = trustGrammar[verb];
  if (!rule || args.length !== rule.arity ||
      (rule.slots && !rule.slots.includes(slot)) ||
      args.includes('--')) {
```

```js
export async function applyRestoreCandidate(input) {
  const confirmed = await input.confirmationStore.readConfirmed(input.contextId);
  const candidate = await input.candidateStore.readActive(confirmed.candidateId);
  const lock = await input.slotLocks.acquire({
    projectIdentityDigest: confirmed.projectIdentityDigest,
    slot: confirmed.slot,
  });
  let transaction = null;
  try {
    transaction = input.createTransaction(confirmed, candidate);
    await runFinalBarrier({ ...input, confirmed, candidate, transaction });
    await input.confirmationStore.spend(confirmed.contextId, transaction.transactionId);
    await input.candidateStore.markApplyInProgress(
      candidate.candidateId,
      confirmed.contextId,
      transaction.transactionId,
    );
    return await runApplyTransaction({ ...input, confirmed, candidate, transaction });
  } catch (error) {
    if (transaction &&
        await input.candidateStore.isApplyInProgress(candidate.candidateId)) {
      await input.candidateStore.consume(candidate.candidateId, {
        outcome: 'failed-before-replacement',
        transactionId: transaction.transactionId,
        errorCode: classifyPublicError(error),
      });
    }
    throw error;
  } finally {
    await lock.release();
  }
}
```
