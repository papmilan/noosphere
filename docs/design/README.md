# Design history

The dated specifications and implementation plans in this directory preserve
Noosphere's design history. They describe the command names and rollout state
that existed when each document was written; unchecked plan boxes are not an
active project backlog.

For current behavior and CLI syntax, use the normative protocol references:

- [Continuation State Protocol v1](../../CSP.md)
- [Agent Cognitive-state Protocol](../ACP.md)

In particular, historical ACP examples may use `noosphere state` commands
that now live under `noosphere acp state`. The deprecated aliases remain only
for their documented compatibility window.
